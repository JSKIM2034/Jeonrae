## 요청
- (2026-11-23) 2장, 3장에도 1장처럼 풀이 많았으면 좋겠고, 풀 종류도 많았으면 해요. → 두 가지 모두: (1) 땅을 덮는 풀, 들꽃, 덤불 같은 장식 식물을 2·3장에 넉넉히, 지역 분위기에 맞게(2장 산길: 억새, 들국화, 고사리 / 3장 바닷가: 갯메꽃, 해당화, 갈대, 바위 이끼 등) 종류를 늘리기. (2) 1장의 "캐는 들풀/약초"처럼 2·3장에도 캐서 도감에 모으는 풀 종류 추가. 웹 성능(멀티메시 등)을 지키면서.
- (2026-11-23) "엄마" 얼굴이 좀 찌그러져 보여요. 고쳐 주세요. → 사용자는 "3장 엄마"라고 했지만 엄마(mom.glb) 캐릭터는 2장 오누이의 엄마예요. 2장 엄마와 3장 해녀(haenyeo.glb) 얼굴을 둘 다 가까이서 찍어 확인하고, 원인이 애니메이션/뼈대 변형, 크기 비율, 텍스처 문제면 코드로 고치기. 모델 자체가 찌그러진 거면 docs/needed_models.md 에 "다시 만들 모델"로 적고 보고에서 사용자에게 Meshy로 다시 만들어 달라고 알리기.
- (2026-11-23) 세계 설계(docs/world_plan.md)의 길 나누기는 사용자가 실제로 걸어 봐야 판단할 수 있다고 해요. 그러니 집 마을과 길 잇기를 만들 때 플레이해 볼 수 있는 상태로 빨리 보여 주기를 우선해 주세요.
- (2026-11-22) 플레이 시간이 30분도 안 돼요. ROADMAP.md 순서대로 분량을 매일 조금씩 늘려 주세요.
- (2026-11-22) PC 조작(WASD, 오른쪽 버튼 시야, 스페이스 점프, E/엔터)과 휴대폰 터치 조작이 둘 다 계속 잘 되게 유지해 주세요.
- (2026-11-22, 처리함 2026-11-22) 3장 결말 정리: 지금은 자라에게 산삼을 주든 위로만 하든, 끝난 뒤 용궁에 가면 용왕이 똑같이 "고맙소, 뭍의 아이여..."라고만 해서 이상해요. 1장처럼 결말에 따라 달라지게 해 주세요.
  - 산삼을 준 경우: 용왕이 건강해진 모습으로 직접 고마워하고, 용궁 사람들도 반겨 주기 (작은 보상).
  - 위로만 한 경우: 용왕은 아직 앓아누워 있고, 자라가 시름에 잠겨 있음. 이때 플레이어가 산삼을 다시 구해(뒷산) 가져다주면 늦게라도 낫게 하는 '두 번째 기회' 퀘스트로 이어지기 (플레이 시간도 늘어남).
  - 결말 카드 문구도 각각 용왕이 어떻게 됐는지 알 수 있게 고치기. 엔딩 모음(도감)에 3장 엔딩도 1장처럼 기록되게.
